02 / Fonctionnalités

Conçu pour
l'atelier.

Une interface pensée pour les équipes terrain — rapide, lisible, accessible depuis un smartphone ou un poste fixe, même avec une connexion limitée.

Stack technique
React 18 Vite 5 Supabase PostgreSQL PWA Service Worker Offline-ready Mobile-first
01
Progressive Web App
Installable sur Android, iOS et desktop. Mode hors-ligne avec synchronisation automatique au retour de connexion.
02
Recherche intelligente
Autocomplete sur désignations, immatriculations et codes pièces. Résultats instantanés depuis le catalogue local.
03
Fiche OR complète
Création d'ordres de réparation avec machine, immatriculation, type de panne, technicien assigné et pièces consommées.
04
Catalogue filtration véhicules
Base de données VP/VU et engins lourds avec tous les consommables : filtres, plaquettes, disques, pneumatiques, AdBlue.
05
Synchronisation temps réel
Backend Supabase avec abonnements temps réel. Chaque modification est visible instantanément sur tous les postes connectés.
06
Interface sans formation
Conçu pour une prise en main immédiate par les équipes maintenance et magasiniers sans formation préalable.
